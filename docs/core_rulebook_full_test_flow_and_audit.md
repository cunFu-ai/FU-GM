## 总结

FU-GM 已经具备完整跑团骨架：第零章、角色创建、检定、命刻、冲突、HP/MP/IP、休息、旅行、地下城、仪式、工程、购物奖励、NPC/遭遇设计、成长、长期故事节奏和完整 txt 记录都已有实现。

经过 2026-06-23 的 P0/P1/P2 实施后，FU-GM 已补齐核心跑团流程中最影响自主运行的硬规则入口：检定后援用、机会选择、冲突装备、团队合作、先攻团队检定、羁绊管理、出售、缺席和 PVP 安全流程，以及核心生物图鉴基础库。

当前仍不是“规则书全自动级”。剩余缺口主要集中在四类：

1. 职业技能和英雄技能：75 个职业技能和 31 个英雄技能已有机器可读覆盖表，区分 `hard_rule`、`passive_hard`、`gm_judgement`、`reference_only`；少数强叙事技能会保持 GM 判断，不强行改数值。
2. 生物图鉴复杂行动：56 个核心生物条目均已补入攻击、法术、其他行动或关键特性文本，可供 GM 调用；极复杂效果仍以结构化提示、命刻和 GM 判断处理，不全部写成机械规则。
3. 稀有物品和神器：核心样例库可检索，预算和设计工具已有；神器级效果仍应以 GM 判断为主，不宜全部机械化。
4. 长跑真实对话压力：已完成一次完整 S0 到第一章收团的真实 API 长跑测试；后续仍应作为回归测试持续验证表达层自然度、上下文稳定性和错误恢复体验。

有些规则不建议做成硬编码。比如“何时要求检定”“如何描述场景”“怎样塑造反派”“地下城是否值得出现”“首领战怎样震撼”本质是 GM 判断。FU-GM 应通过提示词、审计面板和测试来约束，而不是机械拦截。

## 可复用全规则长跑测试流程

目标：用一套接近真实跑团的对话脚本，覆盖核心规则书中非可选规则。可选规则只检查“默认不触发”，不纳入流程成功条件。

建议测试名：`FULL_CORE_RULEBOOK_CAMPAIGN_REGRESSION`

建议参与者：5 名玩家，覆盖 15 个职业的起点组合。

| 玩家 | 角色方向 | 初始职业组合 |
| --- | --- | --- |
| 阿凛 | 前排守护、武器战术、爆发怒火 | 守护者 2 / 武器大师 2 / 怒焰斗士 1 |
| 赛璃 | 治疗、元素魔法、知识调查 | 御魂使 2 / 元素使 2 / 博学家 1 |
| 洛岚 | 远程、潜入、道具与魔导机关 | 浪客 2 / 神射手 2 / 造物使 1 |
| 伊莉雅 | 交涉、时间熵术、旅途组织 | 游说家 2 / 熵术士 2 / 旅人 1 |
| 白河 | 奥灵、怪物法术、暗影代价 | 奥灵使 2 / 拟兽使 2 / 暗刃骑士 1 |

测试全局设置：

- 固定随机种子，保存所有后端 action payload、表达层文本、延迟统计和 txt 完整记录。
- 禁用可选规则：以代价换成功、以援用换失败、联合决定检定属性、偷袭轮、冲突外玩家重掷、战斗制霸、打造特殊效果。
- 所有数值结算必须来自后端 payload，表达层不得改写骰子、公式、HP/MP/IP、命刻格数。
- 每次检定公开：属性、骰面、修正值、结算值、高值、目标值、是否大成功/大失败、机会数量。
- Session 0 完成或玩家要求进入第一章前，必须完成所有 PC 角色硬校验；地图生成状态仅作为后台门禁/审计信息，不向玩家播报“地图生成中”等出戏文本。

### 0. 预检

目的：确认服务、AstrBot 接入、规则库、地图、记录器、延迟监控都在线。

玩家话术：

- “我们开始新团，从第零章开始。”
- “先看看当前服务状态和记录文件路径。”

必须触发：

- 运行状态面板写入服务状态、模型状态、AstrBot 状态、地图渲染器状态、规则库版本、当前场景。
- 新建 campaign/session，生成 `.jsonl` 和 `.txt` 记录路径。
- `phase.current_scene` 显示 Session 0。

验收点：

- 不能在群聊里泄露后台 commit、数据库保存成功、内部 JSON。
- txt 记录在第一条消息后已经存在，且逐条换行。

### 1. Session 0 - 安全、基调、八大支柱

目的：覆盖第零场、安全工具、共同责任、八大支柱、世界共创入口。

玩家话术：

- 阿凛：“我想要宏大但不压抑，反派可以悲剧，但不要过度血腥。”
- 赛璃：“界限是儿童受害细节，帷幕是酷刑和身体恐怖。”
- 洛岚：“我想有古代遗迹、魔导科技、不同国家互相不信任。”
- 伊莉雅：“我希望故事里有能被弥合的社会冲突。”
- 白河：“奥灵和灵魂之河要很重要。”

必须触发：

- 写入 `safety_lines`、`safety_veils`。
- 写入核心主题、魔法科技地位、社会冲突、灵魂能量、古代遗迹、危机世界。
- 不询问“世界形状”。当前项目用 Nortantis 类地球大陆地图，只允许后台生成地图基础分类。

验收点：

- GM 应自然追问“你们最想看到怎样的冲突/希望/代价”，不能机械说“请给创建世界流程选择”。
- 世界风格、地图形式、map_card 等后台分类不应对玩家明说。

### 2. Session 0 - 世界创建与地图准备

目的：覆盖创建世界、王国、历史事件、奥秘、世界威胁、预备地点库调用。

玩家话术：

- 阿凛：“赤羽遗民守着一座白花碑驿站，风铃内侧刻着失去的名字。”
- 赛璃：“每年归潮祭后都会少一座岛，但所有人的公开记忆会自动改写。”
- 洛岚：“第七采掘城在抽取地底灵魂能量，财团说这是拯救世界。”
- 伊莉雅：“海上王国奥涅里亚靠灯塔舰队维持贸易，但王室正在衰弱。”
- 白河：“边境有一片沉默森林，里面的奥灵拒绝回应人类。”

必须触发：

- `kingdoms`、`factions`、`historical_events`、`mysteries`、`world_threats` 只存客观设定，不把“我投这个”“我补充反派种子”混进谜团。
- 每个公开地点同步写入 `map_locations`，并按语义设定 `feature_type` 和图标。
- 预备地点库只作为 GM 后台灵感，不能把所有地点直接公开塞进世界。
- 若出现重复地点名，如“边境起始王国”和“奥涅里亚”指同一概念，应合并为奥涅里亚。

验收点：

- 地图生成开始后，要在状态面板显示进行中/完成/失败原因。
- 第零章结束前必须有至少一个起始地区、若干可旅行地点和路线旅行日。

### 3. Session 0 - 队伍主题与第一幕

目的：覆盖创建队伍、共同目标、羁绊种子、第一幕投票。

玩家话术：

- 阿凛：“我们是被奥涅里亚委托调查失踪群岛的临时调查队。”
- 赛璃：“队伍的共同物资由白花守望会资助，但他们希望我们带回失名者的真相。”
- 洛岚：“我投第一幕从白花碑驿站开始，因为那里能把所有线索接起来。”
- 伊莉雅：“我担心财团通缉我们，想从外交身份切入。”
- 白河：“我和某个沉默森林的奥灵有旧债。”

必须触发：

- `PartySheet` 写入队伍主题、共享资源、常用消耗品、遇到的角色/地点。
- 第一幕候选不超过 3 个，投票元数据不能污染世界事实。
- 给每名 PC 生成至少一条羁绊建议。

验收点：

- 如果世界创建已足够完整，FU-GM 可以提前异步生成地图；如果地图未完成，不得直接进入第一章。

### 4. Session 0 - 角色创建硬校验

目的：覆盖身份、主题、故乡、职业、属性、技能、法术、装备、初始资源、角色卡。

玩家话术：

- 每名玩家给出身份、主题、故乡、2-3 个职业共 5 级、四属性、5 个技能等级、职业授予法术、初始装备、金币消耗、至少一段羁绊。
- 故意让一名玩家漏掉法术或装备：“我先这样，直接开跑吧。”

必须触发：

- 未完成角色时不能进入第一章，GM 应指出缺失项。
- 属性必须是合法起始分配，职业总等级必须 5，职业数量 2-3。
- 起始金币和装备权限必须结算。
- HP/MP/IP、物防、魔防、先攻、武器命中公式、初始物语点生成。

验收点：

- 不得用预制角色跳过创建。
- 角色字段完整后才允许 `CharacterCreationManager.create_player_character`。

### 5. 第一章开场 - 标准场景与无需检定原则

目的：覆盖场景开始、GM 描述、玩家行动、何时不检定、公开记忆和暗线记忆。

玩家话术：

- 阿凛：“我去问驿站守望会今日有没有来客。”
- 赛璃：“我查看风铃刻名。”
- 洛岚：“我只是找水井和马棚，不做冒险动作。”

必须触发：

- 找普通水井不检定。
- 调查风铃可做开放检定。
- 公开发生的事实进入公开记忆；尚未发生或玩家不知道的反派行动进入暗线记忆。

验收点：

- 仪表盘可查看公开记忆，暗线记忆需要 GM 明确展开，不自动向玩家暴露。

### 6. 检定、团队检定、援用与机会

目的：覆盖属性检定、开放检定、团队检定、对抗检定、情境修正、大成功/大失败、特质/羁绊援用、机会。

玩家话术：

- 赛璃：“我用洞察和意志判断风铃里的名字是否被导向灵魂之河。”
- 白河：“我协助赛璃，描述奥灵回声。”
- 若失败，赛璃：“我消耗 1 物语点援用主题‘怜悯’，重掷低的那枚。”
- 若仍差一点，白河：“赛璃对我有信赖羁绊，她能不能消耗 1 物语点加羁绊强度？”
- 若掷出双 7，GM 必须高亮“大成功”，并询问或推荐机会效果。

必须触发：

- 属性检定永远只有两枚骰子。
- 团队检定支援 DL10，成功支援者 +1，最高羁绊强度只加一次。
- 大成功是两个相同且均大于等于 6 的点数。
- 大失败是双 1，PC 得 1 物语点。
- 机会列表至少可选：揭示、进展、纽带、情报、青睐、审视、失态、失物、受苦、优势、转折。

验收点：

- 当前状态：援用特质、援用羁绊和通用机会选择器已实现；真实长跑测试要重点检查表达层是否自然说明物语点消耗、重掷和机会选择。

### 7. 玩家改变故事与物语点

目的：覆盖物语点获得、消耗和向故事加入新元素。

玩家话术：

- 伊莉雅：“我想声明白花守望会有一条避开财团关卡的旧路，我愿意消耗物语点。”

必须触发：

- 若是新事实且会改变当前局势，消耗 1 物语点。
- 写入公开事实或地图路线，不能仅口头承认。
- 若不合理，GM 应解释为什么不能这样加入，而不是默默拒绝。

验收点：

- 物语点减少、世界状态更新、路线旅行日生成。

### 8. 社交冲突场景

目的：覆盖冲突场景不等于战斗、先攻、轮和回合、推进目标、目标命刻、调查、妨碍、防御。

玩家话术：

- 场景：队伍觐见奥涅里亚摄政王，说服她不要把调查权交给第七采掘城。
- 伊莉雅：“我提出外交证据，推进‘争取摄政王信任’命刻。”
- 洛岚：“我调查监察官艾蕾娜的动机。”
- 阿凛：“我防御式站位，掩护赛璃不受近身威胁。”
- 白河：“我妨碍艾蕾娜，让她动摇。”

必须触发：

- 冲突开始前确定参与者和各方目标。
- 玩家方进行 `DEX+INS` 先攻团队检定，对抗敌方最高先攻值。
- 每轮双方交替行动，多行动精英/悍将也不能在还有 PC 可行动时连续行动。
- 推进目标命刻按成功差值填格。

验收点：

- 当前状态：`StartConflict` 已执行先攻团队检定并生成交替顺序；冲突团队合作已支持“支援自动成功但消耗本轮回合”。长跑测试要确认 GM 不会跳过这些公开结算。

### 9. 旅行与地图

目的：覆盖旅行日、威胁等级、旅行事件、地图路线、交通工具、旅行服务。

玩家话术：

- 队伍从白花碑驿站走旧路去奥涅里亚边境港。
- 旅人伊莉雅负责路线，其他人描述路上活动。
- 洛岚购买渡船服务或租用陆行兽。

必须触发：

- 旅行日表示徒步一天的地图距离，不再询问玩家“旅行日长度”。
- 通过 `WorldState.map_routes` 计算旅行天数，Nortantis 坐标只用于视觉布局。
- 按威胁等级掷旅行骰，生成发现、危险或无事。
- 服务费用、交通工具购买或拥有状态写入。

验收点：

- 地图路线和旅行天数一致。
- 地图视觉不能反向决定规则距离。

### 10. 地下城探索

目的：覆盖地下城三种探索方式、地下城准备、区域、危险命刻、陷阱、奖励、关键点。

玩家话术：

- 队伍进入“潮汐下的钟塔遗迹”。
- GM 使用地下城场景或细致探索，不使用幕间跳过关键区域。
- 洛岚：“我检查地板机关。”
- 赛璃：“我读墙上的古代仪式说明。”
- 阿凛：“我挡住从水道涌来的构装体。”

必须触发：

- 地下城有风格、目的、威胁、奖励、关键点。
- 至少一个危险命刻，例如“潮水没顶”。
- 探索失败推进危险命刻。
- 宝箱和奖励按队伍等级/人数预算发放。

验收点：

- 探索记录进入场景日志；奖励进入背包/金币/IP。

### 11. 战斗冲突

目的：覆盖攻击、施法、防御、妨碍、消耗物资、推进目标、调查、技能、装备、距离、飞行、多重攻击、双持、相性、异常、危机、0 HP。

玩家话术：

- 敌人：一只飞行构装体、两名财团士兵、一名精英监察官。
- 阿凛：“我先用防御掩护赛璃。”
- 赛璃：“我施放治愈术治疗阿凛。”
- 洛岚：“我双持手枪攻击两个目标。”
- 伊莉雅：“我用妨碍让监察官动摇。”
- 白河：“我调查飞行构装体的数据。”
- 阿凛：“我用装备动作换上长枪和盾。”
- 赛璃：“我用雷霆击打飞行构装体，看看能否迫使它落地。”

必须触发：

- 攻击用武器命中公式，命中后用高值计算伤害。
- 治愈术等固定治疗从法术库取固定值，不能让表达层编造恢复量。
- 飞行目标不能被普通近战攻击命中，除非有飞行或可触及方式。
- 弱点、抵抗、免疫、吸收即时公开。
- 状态效果立即影响骰级或行动限制。
- 进入危机状态时公开提醒。
- PC HP 到 0 后，由玩家选择投降或牺牲；NPC/反派按规则处理。

验收点：

- 当前状态：冲突 `Equip` 动作已实现；PC 0 HP 底层有投降/牺牲流程。真实跑团中仍必须先询问玩家选择，不能由系统替玩家决定。

### 12. 冲突中的仪式与命刻倒转

目的：覆盖仪式学派、能效、范围、MP 费用、准备命刻、协助仪式、冲突中阻止仪式。

玩家话术：

- 赛璃：“我计划御魂仪式，确认失名者灵魂是否被第七采掘城牵引。”
- 白河：“我贡献仪式，用奥灵知识稳定回声。”
- 敌方女巫开启“灵魂泵启动”10 格命刻，每轮自动推进。
- 阿凛：“我攻击支柱，推进目标来倒转仪式命刻。”

必须触发：

- 仪式前提校验：角色是否掌握对应学派。
- 能效和范围只能使用枚举值，非法词如“小型”不能抛给玩家，应转换或解释需要选择何种规则项。
- 冲突中仪式使用命刻，完成后才可施放。
- 仪式不能直接持久生成装备或消耗品。

验收点：

- 失败时输出可恢复的规则说明，而不是 Python 异常文本。

### 13. 物资点、购物、工程与奖励

目的：覆盖 IP、消耗品、炼金/魔导、购物、住宿、交通、工程、帮工、奖励预算、稀有物品设计。

玩家话术：

- 洛岚：“我消耗 IP 现场调一瓶解药。”
- 队伍在港口住宿、补给、购买一件基础装备。
- 洛岚启动工程：“修复白花守望会的旧式信号塔。”
- 赛璃和阿凛帮忙工作一天，雇佣两名工匠。

必须触发：

- IP 消耗和效果固定结算。
- 商品价格、住宿费用、旅行服务费用硬结算。
- 工程材料费、进度、帮工费用和完成状态硬结算。
- 奖励预算按队伍最高等级和人数计算。

验收点：

- 稀有物品设计要检查数值强化过多的问题。
- 出售物品已实现为半价回收并移除物品；测试中应确认金币和背包同步更新。

### 14. 反派、终结点与首领战

目的：覆盖反派类型、终结点、反派目标命刻、黑暗镜像、震撼登场、首领设计、精英/悍将、多阶段或多部件。

玩家话术：

- 反派艾蕾娜登场：“你们以为记忆属于人，但记忆只是世界运行的燃料。”
- 她拥有目标命刻“启动灵魂中枢”，并使用终结点逃离或恢复。

必须触发：

- 反派登场时每名 PC 获得物语点奖励，且每场景上限按规则控制。
- 反派终结点记录，消耗后减少。
- 反派可用终结点逃离、恢复或推动阶段。
- 首领战要有可读行动模式，玩家能调查或通过战斗发现规律。

验收点：

- 当前项目已实现 `register_enemy`、终结点恢复/逃离/阶段推进、反派登场物语点奖励、反派援用特质重掷等底层能力。

### 15. 场次结束、成长与长期节奏

目的：覆盖场次总结、经验、升级、职业精通、英雄技能、故事节奏。

玩家话术：

- “我们在这里收团。”
- 每名玩家说一句角色成长、一个未解问题、一个下次想追的线索。

必须触发：

- 收团后 `phase.current_scene` 切到已收团/下一场准备。
- 生成完整 txt 对话、结构化摘要、公开记忆、暗线记忆。
- 经验 = 基础经验 + 终结点消耗 + 物语点均分。
- XP 到 10 可升级，职业最多 10 级，角色最多 50 级。
- 20/40 级属性提升、职业精通获得英雄技能。

验收点：

- StoryArcManager 不生成重复反派种子，不把 JSON 字符串当标题。
- 下一场议程要保留当前悬念、反派压力、地点状态。

### 16. 测试专用外传插入

目的：在不破坏真实团感的前提下，覆盖低等级自然跑不到的规则。

建议方式：把它描述为“未来可能性训练场”或“规则回归外传”，不写入正史。

覆盖项：

- 所有法术定义逐个跑固定效果、攻击效果、状态效果、场景持续效果。
- 所有职业技能至少触发一次：硬实现技能应真实结算；参考型技能应返回“已识别但未完全建模”的清晰提示。
- 所有英雄技能至少做获得资格校验；已有硬效果的技能要跑结算。
- 八个 NPC 物种各设计一个敌人，测试小兵、精英、悍将、飞行、反应、特殊攻击、施法者、危机效果。
- 每类基础装备、稀有武器、防具、盾牌、饰品、神器样例至少一件。

验收点：

- 这部分不追求正史叙事连贯，但要保持人类可读的训练场对话。

## 不建议硬做进 FU-GM 的内容

- “何时需要检定”：应由 GM 根据风险、阻碍、后果判断。
- 场景开场和结束的文学表达：应由表达层完成，系统只给约束。
- 玩家是否能提出某个世界事实：系统应检查物语点和安全边界，但不要机械阻止创意。
- 地下城是否值得出现、探索详略：应由 GM 根据故事重要性决定。
- 反派的悲剧根源、说话方式、震撼亮相：应给 GM 指导和记忆，而不是模板化输出。
- 首领战的固定模式和环境机制：可提供结构工具，不应限制为少数写死机制。
- 玩家对玩家冲突：需要安全确认和团桌共识，默认不应开放硬结算。

## 建议实现优先级

P0，高优先级：

1. 通用检定后窗口：援用特质重掷、援用羁绊加值、消耗物语点、重算大成功/大失败/总值。
2. 通用机会选择器：把 11 种机会效果做成 Action 或后续决策流程。
3. 冲突 `Equip` 动作。
4. 冲突团队合作：支援自动成功，消耗本轮回合，影响当前检定。
5. 先攻团队检定自动流程：根据敌方最高先攻生成首轮行动方和交替顺序。
6. 反派登场物语点奖励和反派援用特质重掷。

P1，中优先级：

1. 羁绊管理器：建立、强化、更改、抹除、最多 6 段、情感互斥、休息场景入口。
2. 0 HP 玩家选择流程：必须询问投降或牺牲，不能默认。（询问时可以只是询问玩家选择，但做出的动作必须是投降或牺牲）
3. 技能覆盖表：把 75 个职业技能分成“已硬结算、被动已结算、需要 GM 判断、未实现”四类，并为每类写测试。
4. 核心法术逐项测试夹具，特别是固定治疗、场景持续、状态免疫、武器附魔、叙事法术。
5. Session 0 抽取清洗：进一步剥离投票/闲聊/反派种子，避免污染世界字段。

P2，低优先级或内容型：

1. 完整录入核心生物图鉴为结构化 bestiary。
2. 完整录入核心稀有物品样例和神器样例。
3. 出售物品、缺席玩家处理、PVP 安全流程。
4. 更多地下城备用库和首领战模板。
